# Configuration

## Mod Configuration

This mod has no runtime configuration. All behaviour is defined by static data files.

## Game Settings Affecting Mod Behaviour

| Setting | Effect on Mod Empires |
|---------|----------------------|
| Galaxy size | Determines number of AI empires spawned; more slots = more mod empires appear |
| AI empire count | Directly limits how many of the 26 mod empires can spawn as AI |
| Fallen empire count | Controls whether Drengin/Protoss can spawn as fallen empires |
| Advanced AI starts | Affects starting resources for mod AI empires |
| Ironman mode | No effect on mod content availability |

## Launcher Settings

| Setting | Value |
|---------|-------|
| Mod enabled | Must be checked |
| Dependencies enabled | All 3 must be checked |
| Load order | Automatic (enforced by launcher) |

## No User-Editable Config Files

- No `.ini`, `.json`, `.yaml`, or `.txt` config files in mod.
- No in-game mod options menu.
- No console commands added by mod.
