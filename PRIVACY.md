# Privacy and Personal Data

This document describes privacy and personal data handling for Universum Infinitum: Prescripted Countries, a Stellaris mod installed as local game content. As checked on 21 October 2026, the mod's files do not request, collect, transmit, or store personal data. This technical description covers the mod itself, not separate data practices of the game or distribution platforms.

## 🔎 What This Document Covers

This document describes how Universum Infinitum: Prescripted Countries at https://github.com/hmlendea/stellaris-ui-prescripted-countries handles personal data. It covers the application behaviour and verified integrations described below. Where the software is self-hosted, the instance operator may have separate responsibilities described below.

## 📥 Data We Handle

### Data Provided to the Application

- The mod does not request personal data. Player-created names and other game choices are handled by Stellaris, not collected by this mod.

### Data Generated or Collected by the Application

- The mod does not automatically collect personal data, telemetry, diagnostics, or usage data.

### Data Received from Integrations

- The mod receives no personal data from integrations or third parties.

## 🧭 Processing and Use

The application processes the data described above for these verified functions:
- Loading the mod's preset country definitions — no personal data is involved
- Loading the mod's English localisation strings — no personal data is involved

## 🗄️ Storage, Retention, and Deletion

The mod consists of static game configuration and localisation files installed with Stellaris. It does not create a separate account, database, telemetry store, or log of personal data. There is no personal data handled by the mod to retain or delete. Any data stored by the game or a distribution platform is outside this mod's control and is governed by that product's settings and policies.

## 🔗 External Processing and Integrations

The mod has no built-in external data transfer, external processing service, or runtime integration that receives personal data. Distribution platforms may process data when users access their services; those practices are separate from this mod and are not controlled by its files.

## 🛡️ Data Protection and Security

The mod does not process or store personal data and contains no service or telemetry component. It is distributed as game configuration and localisation content. Users remain responsible for the security of their devices, game installation, accounts, and any distribution-platform services they use.
